# 먼작귀 퍼즐 토벌 대작전! (비공식 팬게임)

> ⚠️ **이 게임은 비공식 팬게임입니다.**
> 원작자 나가노 및 치이카와 제작위원회와 아무 관계가 없으며, 승인이나 후원을 받지 않았습니다.
> 비영리로 만들었고, 수익을 내지 않습니다.
> 권리자께서 요청하시면 바로 내리겠습니다.

**플레이:** https://chiikawa.3match.workers.dev

**출처:** 게임에 들어간 그림·소리를 파일마다 [CREDITS.md](CREDITS.md)에 적어 두었습니다 (게임 안 설정 → 만든 사람·출처, 웹 `credits.html`)

'먼가 작고 귀여운 녀석들' 캐릭터 얼굴을 맞추는 3매치 퍼즐에 괴물 토벌 전투를 더한 브라우저 게임입니다.

## 놀이 방법

- 옆 칸의 얼굴과 자리를 바꿔 같은 얼굴 3개 이상을 맞추면, 그 캐릭터가 괴물을 공격합니다.
- 카니를 맞추면 공격 대신 체력을 회복합니다. 우사기는 가끔 치명타("우라!")를 냅니다.
- 연쇄로 터질수록 피해가 커집니다.
- 괴물은 몇 턴마다 반격합니다. 체력이 다 떨어지면 후퇴합니다.
- 특수 구슬
  - 4개 한 줄: 한 줄을 지우는 줄폭탄
  - L, T 모양: 주변을 터뜨리는 폭탄
  - 5개 한 줄: 한 캐릭터를 전부 지우는 무지개 폭탄
  - 특수 구슬끼리 바꾸면 더 큰 효과
- 남은 체력에 따라 별 1~3개

- 떨어지는 동안 두기 (일상 퍼즐): 연쇄가 도는 중에도 판이 다 찬 뒤라면 이미 내려앉은 얼굴끼리 바꿀 수 있음. 맞으면 이동 1을 쓰고 도는 연쇄가 같이 터뜨림 (콤보는 새로). 아이템·장애물·떨어지는 칸은 못 잡고, 토벌(괴물 턴)·시간 판은 연쇄가 끝날 때까지 기다림 (`game.js` quickSwap)

### 아이템

- 4개 한 줄: 🚀로켓(한 줄), L·T 모양: 💣폭탄, 5개 한 줄: 🌈무지개, **2×2 네모: ✈️비행기** (목표 쪽으로 날아감)
- 속성: 🔥씩씩 → ⭐엉뚱 → 💧울보 → 🔥씩씩 (화살표 쪽에 1.5배), ☀️빛 ⇄ 🌙어둠은 서로에게 1.5배
- 아이템은 색이 없는 아이콘 하나. **두 번 톡톡 누르거나 아무 쪽으로 쓱 밀면** 바로 발동
- 아이템끼리 바꾸면 한 칸으로 빨려 들어가 합체한 뒤 더 큰 효과 (꿈의집과 같은 조합). 비행기는 상대 아이템을 싣고 날아감
- 아이템은 터지기 전(부르르, 부풀기, 빙글) → 터짐(로켓은 차례로 쓸고, 폭탄은 둥글게, 무지개는 빛줄기, 비행기는 날아가 꽂힘) → 여운(연기, 불씨)

### 모험 지도

50장 500판: 토벌 153개와 일상 퍼즐 347개가 한 줄 루트에 정해진 순서로 섞여 있습니다. 장마다 10판(일상 7, 토벌 3 안팎)이고 마지막 판은 보스. 스테이지마다 판 모양이 다릅니다.

- 1~6장: 풀 뽑기 첫걸음, 섞어 보기, 제초 검정 1급, 하치와레의 노래, 끝나지 않는 오늘, 고블린 동굴 (`js/data.js`, `js/life.js`)
- 7~30장: 라멘 가게 대작전, 비 오는 날, 카니의 헌책방, 여름 축제, 바다로!, 랏코 선생님의 수련, 모몽가 소동, 쿠리만쥬의 하루, 별똥별의 밤, 마법소녀 치이카와, 할로윈 밤, 풍뎅이와 숙제, 가을 소풍, 제초 검정 특급, 눈 내리는 날, 산타의 밤, 새해 첫 해돋이, 우사기의 보물 돌, 온천 마을, 꽃놀이, 하치와레의 첫 공연, 키메라의 숲, 거인의 성, 토벌 대축제 (`js/chapters.js`)
- 31~40장 인어섬 편 「노래를 잃은 섬」: 유리병 편지, 작은 배의 항해, 안개 낀 해변, 산호 숲, 썰물 길, 인어 마을, 랏코의 잠수, 세이렌의 노래, 폭풍의 밤, 다시 부르는 노래. 바닷가에 떠밀려 온 "노래를 돌려줘" 편지를 따라 섬으로 가서, 사라진 노래 진주를 되찾는 이야기 (영화와는 상관없는 이 게임만의 이야기). 인어·세이렌도 대사를 함
- 41~50장 파자마파티즈 편: 파자마 애호회, 초록이의 안무, 관객 0명, 무차페스 초대, 큰 새 습격, 대타 파자마파티즈, 감자 축제 무대, 새 둥지를 찾아, 빗자루 구출 작전, 무차페스. 원작 파자마파티즈 에피소드 흐름을 따라가고(대사는 새로 씀), 500판을 처음 깨면 초록이가 동료로 합류. 포셰트 갑옷 씨·파자마파티즈는 대사에만 나옴(`STORY_CAST`). 무대 판(song: true)을 깨면 결과 창에 「공식 노래 듣기」 링크(게임에 음원은 넣지 않음)

- 일상 퍼즐에는 친구 한 명을 데려가서 그 친구 스킬을 씀 (처음 두 판은 하치와레)
- 스킬 AUTO 버튼: 게이지가 차면 알아서 발동
- 풀 뽑기: 잡초는 칸을 차지한 장애물. 바로 옆에서 맞추거나 아이템으로 뽑기 (큰 잡초는 두 번)
- 요리: 나루토, 달걀, 경단 같은 재료를 맨 아래까지 떨구기 / 시럽·국물: 시럽 칸이 낀 매치로 판 전체에 번지게
- 거품 청소: 한 번 움직일 동안 하나도 못 터뜨리면 거품이 번짐
- 상자, 선물 상자(두 번), 리본에 묶인 구슬(못 움직임, 한 번 터뜨리면 풀림)
- 제초 검정 5급~1급: 제한 시간 안에 목표 (구슬이 터지는 동안 시계는 멈춤)
- 토벌의 미믹은 공격하면서 판에 상자를 던짐
- 인어섬 편(31~40장) 기믹
  - 🐚 조개(판 글자 `c`): 두 번 맞추면 진주가 나옴 (목표 「진주」). 벌어진 채로 한 턴을 그냥 넘기면 다시 닫힘 (`Board.closeClams`)
  - 🏖️ 모래 바닥(`d`): 구슬 밑에 깔린 칸. 그 칸에서 구슬이 터지면 걷힘 (목표 「모래」, `Board.sand`)
  - 🐙 먹물 구슬(`k`): 얼굴이 안 보임(맞추기는 됨). 바로 옆에서 맞추면 씻김 (목표 「먹물」)
  - 🌀 소용돌이(`v` 입구, `V` 출구, k번째끼리 이어짐): 입구 칸 구슬이 더 내려갈 데가 없으면 비어 있는 출구로 빨려 감. 출구가 맨 위인 줄은 새 구슬 대신 소용돌이로 채워짐 (`Board.portals`, 판 모양 `whirl`)
  - 🌊 물살(스테이지 `current: { rows, every }`): 몇 턴마다 정해진 줄의 구슬이 화살표 쪽으로 한 칸씩 밀리고, 끝에 닿은 구슬은 반대쪽으로 돌아 들어옴 (`Board.flow`, `Life.flow`)
  - 🛡️ 보호막 괴물(웨이브 `sh`): 그 괴물에게 강한 속성으로만 보호막이 깎이고(넘친 만큼은 체력), 다른 속성은 1/4만 들어감. 이름 옆에 깨는 속성이 보임 (`shieldSplit`, `js/data.js`)
  - 대왕 조개 미믹처럼 `drop: 'clam'`인 미믹은 상자 대신 조개를 던짐
  - 아이콘·조개 그림은 Noto Emoji PNG (`assets/img/items/*.png`, `ITEM_PNG`)
- 파자마파티즈 편(41~50장) 기믹
  - 🎵 박자 줄(스테이지 `beat: { rows, every }`): 몇 턴마다 오는 '쿵' 턴(분홍 줄이 쿵쿵 뜀)에 그 줄에서 터진 구슬마다 음표 (목표 「음표」)
  - 🪑 빈 객석(`a`): 옆에서 맞추면 관객이 앉음 (목표 「관객」)
  - 💡 스포트라이트(`spot: { size, every }`): 노란 조명 안에서 터진 구슬마다 박수, 조명은 몇 턴마다 옮김 (목표 「박수」, `Board.moveSpot`)
  - 🪶 깃털(`f`): 턴마다 바람에 날려 옆 구슬과 자리를 바꿈, 한 번 맞으면 잡힘 (목표 「깃털」, `Board.blowFeathers`)
  - 🧹 빗자루(`z`, 아이템): 밀면 그 줄과 위아래 한 줄씩 세 줄을 쓸어 버림
  - 🦆 큰 새(토벌, `bird`): 공격하면서 친구 하나를 2턴 동안 낚아채 감 (그동안 그 친구 구슬은 공격·게이지 없음). 그림은 애니 장면에서 오려 냄
  - 대사 줄 `['scene', 그림, 설명]`: 애니 명장면 그림을 크게 띄움. 장 배경은 `CHAPTER_BG`(장 이름 → 그림)로 바꿀 수 있음 (`js/game.js`)

### 하드 모드 (`js/hard.js`)

다 깬 장을 더 어렵게 한 번 더. 판 그림과 이야기는 그대로 두고 값만 바꿔서, 새 판을 그리지 않고 500판을 한 벌 더 만듦.

- 열림: 그 장 보통 10판을 다 깨면 그 장의 하드가 열림 (중간 장까지만 간 사람도 앞 장은 하드를 할 수 있음). 장 안에서는 하드 판이 차례로 열림
- 지도 오른쪽 위 「보통 | HARD」 스위치 (하드 장이 하나라도 열리면 보임). 하드 쪽이면 지도에 보랏빛이 돌고 HARD 도장, 판 테두리·장 띠가 보라, 별·잠김은 하드 기록으로. 장 띠의 별 표는 하드 별(아직 안 열린 장은 🔒 보통 10판 다 깨기)
- 일상 퍼즐: 이동 수(시험 판은 시간)가 줄고, 잡초 절반쯤이 큰 잡초, 상자 절반쯤이 선물 상자로. 바꿀 게 거의 없는 판은 빈 칸에 상자 몇 개 (시럽·재료·소용돌이 판은 길이 막혀서 안 깖). 친구 모으기·음표·박수 목표 +15%
- 토벌: 괴물 체력·공격력이 오르고 공격 간격이 1 줄어듦 (최소 2턴, 보스 판은 보스만 또는 졸개만 줄이기도). 친구 레벨 10 기준
- 기록: 별·깬 판은 `Save.data.hard` (`l` 일상, `b` 토벌)에 따로. 깬 스테이지 수·랭킹·별 업적은 보통 기록만 셈. 처음 깬 판 보상(라멘 한 그릇, 장 끝 이야기, 친구 합류)은 보통 판에서만
- 코인은 보통 판의 1.5배. 이야기는 장 첫 하드 판을 처음 할 때 친구 한마디만 (`HARD_LINES`). 하드 판은 응원 선물(여러 번 막힌 판 도움)이 없고, GA 플레이 기록에도 안 섞음
- 하드 장 별 보상: 하드 별 30개를 다 모은 장마다 (코인 두 배, 티켓 +1, 덤은 보통과 같음). 장 별 보상 창의 「보통 | HARD」 탭 (`ChapStar`의 `h`, `Save.data.hard.got`)
- 업적·칭호: 하드 판 1개, 하드로 10장·30장·모든 장, 하드 별 30개 장 10개, 하드 판 100개
- 모든 장을 하드로 깨면 랏코 「가면 히어로」 옷 (이미 있으면 코인 600, `HARD_PRIZE`)
- 값은 `js/hard-data.js` (만든 파일, 아래 「하드 모드 값 재기」)

### 모으기와 꾸미기

- 스테이지를 깨면 코인
- 출석 도장판(첫 판을 깬 뒤부터): 하루에 한 칸, 빠진 날이 있어도 이어서 찍힘. 7일째는 뽑기 티켓 3장 (코인, 경단, 파르페, 주먹밥 순)
- 오늘의 미션(3판 깨면 열림): 날마다 3개 (잡초 뽑기, 구슬 터뜨리기, 5콤보, 토벌, 스킬, 라멘, 뽑기, 쓰다듬기 등). 하나에 60코인, 다 깨면 뽑기 티켓 1장. 지도 왼쪽 위 「미션」
- 장 별 보상: 장마다 10판 × 별 3개 = 30개를 다 모으면 한 번 받음 (코인 100~490, 뽑기 티켓 1~2장, 간식·이어하기권·라멘 서비스권이 장마다 돌아가며). 지도 장 띠에 매달린 별 표(★ 27/30)를 누르거나 미션 창 「장 별 보상」 목록에서 받기 (모두 받기 있음). 업데이트 전에 이미 30개였던 장도 그대로 받을 수 있음 (`Save.data.chapGot`, `ChapStar` in `js/achieve.js`). 라멘 서비스권은 `Save.data.ramenPass`
- 업적·칭호(프로필): 400판 깨기, 모든 장 보스, 별 100/300/600/1200개, 별 30개 장 1·10·40개, 인어섬 기믹(진주·모래·먹물·보호막), 하드 모드 등 46개. 기믹 기록은 이 업적이 생긴 뒤부터 셈
- 호감도: 집에서 하루 한 번 톡 쓰다듬기(+2), 간식 주기(+5, 좋아하는 간식은 +10), 같이 모험을 이기면 +1. 2단계 코인 100, 3단계 이야기, 4단계 뽑기 티켓, 5단계 단짝(공격·회복 +5%)
- 처음엔 치이카와 혼자. 하치와레(1단계), 우사기(2단계), 카니(첫 토벌), 랏코(두 번째 토벌)가 차례로 합류하고, 시사는 라멘 가게에서 수행 중이다가 「시사의 라멘 가게」를 깨면 합류
- 간식으로 데려오기: 모몽가(딸기 파르페 5), 쿠리만쥬(경단 5), 고블린(주먹밥 4). 라멘 가게 문가에 기웃거리는 손님에게 간식을 주면 친구가 됨
- 초록이(파자마파티즈): 50장 마지막 판 「무차페스 대난입」을 처음 깨면 합류 (`RECRUIT.midori`, 속성 씩씩, 스킬 우와 안무·우와 댄스·무대 조명)
- 편성은 1~5명. 빈자리는 응원 친구 구슬로 채워짐 (공격 절반, 스킬 없음). 끝나고 나오는 친구는 가장 많이 때린 MVP
- 하트: 5개까지, 20분마다 하나씩 참. 모험 지도 스테이지를 못 깨거나 하던 중에 나가면 하나 줄어듦 (코인 150으로 다 채우기)
- 기능은 깬 스테이지 수에 따라 열림: 친구들 2, 라멘 가게 4, 집 6, 캡슐 뽑기 8, 도전 10. 열릴 때 그 자리를 비춰 주며 안내
- 라멘 가게: 갑옷 아저씨와 시사에게 말 걸기, 토벌을 새로 깰 때마다 한 그릇(곱빼기: 체력 150 / 진한 국물: 스킬 게이지 반)

- 친구 상세: 레벨, 스탯, 스킬, 옷 갈아입히기 (그림을 통째로 바꿈, `assets/img/skins/`), 레벨 2에 열리는 짧은 이야기

### 도전 (지도 아래 「도전」)

- 인어섬 탐험: 층마다 일상 퍼즐이 나오고 올라갈수록 이동 수가 줄어드는 무한 모드. 실패하면 거기까지 (층마다 +5번 한 번)
- 제초 대회: 60초 동안 최대한 높은 점수. 판 전체 잡초를 다 뽑으면 +2000점과 함께 다시 자람
- 랭킹: 깬 스테이지 수, 인어섬 최고 층, 제초 대회 최고 점수 (구글 로그인 또는 게스트)
- 주간 리그 (`js/league.js`): 일주일(월요일 0시, 한국 시간) 동안 모두 같은 판으로 20번 움직여 점수 겨루기. 하루 5판, 그 주 최고 점수가 순위
  - 판 모양과 블록은 그 주 씨앗으로 정해짐(`boardRand`). 같은 자리에서 같은 수를 두면 누구나 같은 블록이 떨어짐. 시작 아이템·라멘은 못 씀
  - 판 중에는 바로 위 순위 점수가 목표 칸에 보이고, 넘기면 '추월!'
  - 다음 주에 도전 화면을 열면 지난주 순위로 코인 (1위 1000, 2~3위 700, 10위까지 500, 30위까지 300, 100위까지 200, 참가 100)
  - 판은 `WEEK_TWISTS`에 추가 (주마다 차례로 돎). Firestore `league/{그 주 월요일}/scores/{uid}`. **`firestore.rules`를 다시 올려야 순위가 저장됨**

### 홈 화면 앱과 안전장치

- 사파리에서 공유 → 「홈 화면에 추가」 하면 주소창 없이 앱처럼 켜짐 (`manifest.webmanifest`, `sw.js`). 코드는 켤 때마다 새로 받고, 인터넷이 없으면 저장해 둔 걸로 켬
- 플레이어 폰에서 난 에러는 Firestore `errors` 컬렉션에 쌓임 (켤 때마다 최대 8개, 어떤 화면·판·판 크기였는지 함께). Firebase 콘솔 → Firestore → `errors`에서 봄
- 공지사항: 지도 왼쪽 「공지」 버튼(새 글이면 빨간 점). 이미 하던 사람에게는 새 글이 올라오면 지도에서 한 번 열어 줌. 새 업데이트는 `js/notice.js`의 NOTICES 맨 위에 추가
- 앱처럼 쓰기: 9판을 깨면 한 번, 기기·브라우저에 맞춰 홈 화면에 추가하는 법(아이폰 사파리·크롬, 삼성 인터넷, 안드로이드 크롬은 바로 설치 버튼, 카카오톡 등 앱 안 브라우저면 다른 브라우저로 열기). 이미 앱으로 켰으면 안 띄움. 설정 → 「앱처럼 쓰기」
- 설문: 12판을 깨면 지도에서 한 번 「게임 재밌어?」 (별 1~5 + 하고 싶은 말, 말은 안 써도 됨, 보내면 50코인). '나중에'면 10판 뒤 한 번 더. 설정 → 「의견 보내기」로는 언제든. Firebase 콘솔 → Firestore → `feedback`에서 봄 (`stars`, `text`, `cleared` 깬 판 수, `from` auto/settings, `at`) (`js/survey.js`)
- 튕김: 화면이 켜진 채로 페이지가 꺼지면(아이폰이 메모리가 모자라 말없이 끄는 경우 등) 다음에 켤 때 `errors`에 `crash`로 남음. `msg`에 켠 지 몇 분 만이었는지, `ctx`에 마지막 화면(`+sheet`면 친구 상세 창, 강화하던 중), `stack`에 꺼지기 전 지나온 화면 6개. 앱을 내리거나 화면을 잠근 뒤 꺼진 건 안 셈 (`js/guard.js` Alive)
- 판이 20초 넘게 아무 연출 없이 멈춰 있으면 「앗, 판이 멈췄어요」 창이 뜨고 하트를 잃지 않고 다시 시작 (이것도 `errors`에 `stuck`으로 남음)

## 스테이지 만들기 (7장~)

`js/chapters.js`는 만든 파일입니다. 이름·목표·응원 친구·대사는 `tools/stages/spec.js`에 적고, 판 그림·이동 수·별 점수·괴물 체력은 봇이 정합니다.
7~30장은 만든 뒤 `js/chapters.js`에서 대사(말투 고증)와 괴물을 손봤기 때문에, `make.js`는 보통 31장부터만 재고 `js/chapters.js`의 표시 줄(`// ==== 31장부터 …`) 아래만 다시 씁니다. 7장부터 전부 다시 만들려면 `--rewrite-all` (손본 대사가 spec.js 것으로 돌아감).

```bash
node tools/stages/make.js                      # 31장부터 바뀐 판만 다시 재서 js/chapters.js 아래쪽을 새로 씀
node tools/stages/make.js "--only=진한 국물"     # 이 판만
node tools/stages/make.js --all                # 전부 (4코어로 20분쯤)
node tools/sim.js route 100                    # 루트 전체를 봇으로 돌려 판마다 깨는 비율 보기
```

- 봇(`tools/sim.js`)은 `js/board.js`를 그대로 불러와 화면 없이 둠. 둘 수 있는 수를 하나씩 미리 터뜨려 보고 목표에 제일 가까워지는 수를 고름
- 일상 퍼즐: 봇이 깨는 데 든 수의 분포에서 이동 수를 정함 (보통 93%→88%, 도전 85%, HARD 64%→56% 깸, 1~6장을 같은 봇으로 잰 값과 맞춤). 너무 짧거나 길면 장애물 양을 늘리고 줄여 다시 잼. 별은 깬 판 점수(보너스 포함)의 40%·75% 지점
- 토벌: 친구 레벨이 60판 6 → 300판 10으로 오른다고 보고(10이 끝이라 301~400판도 10), 깨는 비율과 싸움 길이(10~18턴)에 맞춰 괴물 체력·공격력을 정함. 보호막(`sh`)은 체력 × 비율
- 41~50장은 40장 목표 그대로. 봇은 큰 새의 낚아채기 같은 괴물 특수 공격은 모름 (다른 괴물도 마찬가지)
- 31~40장 깨는 비율 목표: 30장 값(보통 78%, 도전 68%, HARD 40%)에서 40장까지 조금씩 (보통 76%, 도전 65%, HARD 37%). 봇은 먹물 구슬이 껴야만 되는 매치는 못 본 척함(얼굴이 안 보이니까). 41~50장은 40장 값 그대로. 봇은 큰 새의 낚아채기 같은 괴물 특수 공격은 모름(다른 괴물과 같음)
- 잰 값은 `tools/stages/tuned.json`에 남겨 둬서, 대사만 고치면 다시 재지 않음
- 에디터에서 그린 판: spec.js 옵션에 `map`이 있으면 판 그림은 그대로 두고, `moves`(`time`)·`stars`가 없을 때만 봇이 잼. 친구 모으기 수 `n`, 점수 목표 `score`, 재료 종류 `ing`·수 `ingN` (`make.js` tuneDrawn)

## 플레이 기록 보기 (Google Analytics)

모험 지도 스테이지마다 이벤트를 보냅니다 (`js/stats.js`, 진짜 사이트에서만).

- `level_start`: 스테이지 시작
- `level_continue`: 이어하기 (`method`: free 공짜 +5번 / ticket 이어하기권 / coins 코인)
- `level_end`: 끝 (`result`: clear 클리어 / fail 실패 / quit 중간에 나감 / closed 앱을 닫음)
- `share`: 클리어 자랑하기

끊김 기록 (`level_end`에 같이, 터지고 떨어지고 스킬 쓰는 동안만 잼): `fps`(평균 프레임, 60·120Hz 폰이면 그 근처가 정상), `jank_pct`(0.05초 넘게 걸린 프레임 %), `slow_pct`(30fps 밑 프레임 %), `worst_ms`(가장 긴 프레임), `light`(연출 가볍게 1/0), `dpr`(화면 배율). 기기·OS·브라우저는 GA가 따로 모읍니다.

같이 가는 값: `stage`(1~500), `chapter`, `mode`(puzzle/battle), `difficulty`(normal/challenge/hard), `attempt`(몇 번째 도전), `help`(막힌 판 도움 단계 0~2), `moves_used`, `moves_left`(클리어 때 남은 이동·초), `continues`, `duration_sec`, `stars`, `goals_left`(실패 때 남은 목표 %), `monster_hp`(실패 때 남은 괴물 체력 %), `hp_left`(토벌 클리어 때 남은 체력 %), `wave`

처음 한 번 GA 관리에서 맞춤 정의를 만들어야 보고서에서 스테이지별로 볼 수 있습니다 (2026-11-08에 아래 전부 등록함. GA는 등록한 날부터만 쌓이고, 그 전 판별 기록은 관리자 통계의 유저 기록 `tries`·`fails`로 봄):
1. [GA](https://analytics.google.com) → 관리 → 데이터 표시 → **맞춤 정의** → 맞춤 측정기준 만들기 (범위: 이벤트): `stage`, `chapter`, `mode`, `difficulty`, `result`, `attempt`, `help`, `method`
2. 같은 곳 **맞춤 측정항목**: `moves_used`, `moves_left`, `continues`, `duration_sec`(단위 초), `goals_left`, `monster_hp`, `hp_left`, `stars`, `fps`, `jank_pct`, `slow_pct`, `worst_ms` (끊김은 맞춤 측정기준 `light`, `dpr`도)
3. 탐색 → 자유 형식: 행 `stage`, 열 `result`, 값 `이벤트 수`, 필터 `이벤트 이름 = level_end` → 스테이지마다 클리어·실패·포기 수. 실패가 많은 스테이지는 `tools/stages/spec.js`에서 고치고 `node tools/stages/make.js "--only=이름"`
4. 끊김 보기: 탐색 → 자유 형식, 행 `기기 모델`(또는 `stage`), 값 `fps`·`jank_pct` 평균, 필터 `이벤트 이름 = level_end`. `jank_pct`가 5를 넘는 기기·스테이지가 고칠 곳

막힌 판 도와주기: 아직 못 깬 스테이지를 3번 실패하면 하치와레가 응원 선물(퍼즐 랏코 검 2개 / 토벌 스킬 게이지 반), 5번부터는 더(퍼즐 폭탄+이동 3번 / 토벌 체력 +20%). 클리어 자랑하기: 결과 창 '자랑하기' → 지역 풍경·로고·MVP 친구·별이 든 카드 그림을 공유 (`js/share.js`)

## 관리자 통계 (엑셀로 받기)

`admin.html`을 열고 관리자 구글 계정(`firestore.rules`의 `isAdmin()`, 지금은 kazu809ha@gmail.com)으로 로그인 → 「엑셀로 받기」. 열 때마다 Firestore에서 새로 읽어서 앞으로 들어오는 설문·기록도 그대로 들어감 (`js/admin.js`).

- 시트: 요약 / 유저(깬 스테이지·별·보유·모은·쓴 코인·플레이 시간·뽑기 횟수·친구 수·옷 수·간식·조각·인어섬·제초 대회·칭호, 업적 누적 기록) / 친구(유저마다 친구·레벨·입은 옷) / 옷 / 설문 / 에러(튕김 포함)
- 유저 기록은 로그인(구글·게스트)한 사람만 계정(`users`)에 있음. 판을 하나라도 깨면 자동으로 게스트가 됨
- 모은·쓴 코인과 플레이 시간(화면이 보이는 동안)은 `Save.data.stat`이 생긴 날(유저 시트의 '통계 시작일')부터 셈 (`js/meta.js` Track). 뽑기 횟수는 예전부터 있던 업적 기록(`ach.n.gacha`)
- 처음 한 번: `firestore.rules`를 올려야 관리자가 읽을 수 있음 (콘솔 → Firestore → 규칙에 붙여 넣고 게시)

## 배포 (Cloudflare)

### 자동 배포 (GitHub Actions)

main에 올리면 `.github/workflows/deploy.yml`이 코드 문법·스테이지·출처 점검 → `dist/` 만들기 → Cloudflare 배포까지 합니다. 저장소 **Actions** 탭에서 진행 상황을 보고, 점검이 실패하면 배포는 안 나갑니다. 손으로 다시 돌리려면 Actions → 배포 → Run workflow.

처음 한 번 저장소 **Settings → Secrets and variables → Actions → New repository secret**:
- `CLOUDFLARE_API_TOKEN`: Cloudflare 대시보드 → 내 프로필 → API 토큰 → 토큰 만들기 → 'Workers 편집' 템플릿
- `CLOUDFLARE_ACCOUNT_ID`: Cloudflare 대시보드 → Workers 및 Pages 오른쪽의 계정 ID
- `FIREBASE_SERVICE_ACCOUNT` (규칙 자동 배포, 선택): Firebase 콘솔 → 프로젝트 설정 → 서비스 계정 → 새 비공개 키 생성 → JSON 내용 전체. 있으면 `firestore.rules`가 바뀔 때 `.github/workflows/firestore-rules.yml`이 규칙도 올림

유료 이펙트 원본(`assets/king`)은 저장소에 없어서, 자동 배포는 지금 사이트에 올라가 있는 뒤섞은 팩(`js/king-pack.js`)을 받아 그대로 다시 올립니다. 팩을 새로 만들었을 땐 컴퓨터에서 한 번 손으로 배포하세요.

### 잠시 닫기 (점검 화면)

저장소 맨 위에 `MAINTENANCE` 파일이 있으면 자동 배포가 게임 대신 `maintenance/`의 빈 화면(아무것도 안 뜸)만 Cloudflare에 올립니다. 예전에 깔린 홈 화면 앱(서비스 워커)과 저장해 둔 그림도 지워서 오프라인에서 옛 게임이 뜨지 않게 합니다. 다시 열려면 `MAINTENANCE` 파일을 지우고 main에 올리면 됩니다 (유료 이펙트 팩은 점검 중에도 사이트에 남겨 둬서 다시 열 때 그대로 받아 감). GitHub Pages 주소는 따로: 저장소 Settings → Pages에서 끄기.

## 랭킹 서버 (Firebase)

설정 전에는 랭킹 없이 기기 안 기록만 씁니다. 켜려면:

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만들고 **웹 앱**을 추가합니다.
2. **Authentication → 로그인 방법**에서 `Google`과 `익명`을 켭니다. 게스트로 하다가 구글을 연결하면 그 기록이 그대로 이어지고, 로그인하면 진행이 계정에 저장되어 다른 기기에서도 이어서 할 수 있습니다.
3. **Authentication → 설정 → 승인된 도메인**에 `chiikawa.3match.workers.dev`(와 `gammja17.github.io`)를 추가합니다.
4. **Firestore Database**를 만들고 저장소의 `firestore.rules`를 올립니다: `npx firebase-tools deploy --only firestore:rules` (또는 콘솔 **규칙**에 그 파일 내용을 붙여 넣기). 아래는 예전 요약이고, 에러 모으기(`errors`)·설문(`feedback`)·주간 리그(`league`)까지 들어 있는 건 `firestore.rules`입니다.
5. 웹 앱 설정값(`apiKey`, `authDomain`, `projectId`, `appId`)을 `js/firebase-config.js`의 `window.FIREBASE_CONFIG`에 넣습니다. 이 값은 공개되어도 되는 값이고, 실제 보호는 아래 규칙이 맡습니다.

**로컬 테스트는 실제 DB에 안 붙습니다.** `localhost`·`127.0.0.1`·`192.168.x` 같은 내 PC나 같은 와이파이 주소, `file://`로 열면 `js/firebase-config.js`가 설정을 비워서 랭킹·저장·게스트 계정이 실제 Firebase에 생기지 않습니다. 테스트 판 기록이 진짜 랭킹에 섞이는 걸 막으려는 것이고, 꼭 붙여서 시험해야 하면 주소 끝에 `?net`을 붙입니다(예: `http://localhost:8770/?net`).

```
rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid
        && request.resource.data.data is string && request.resource.data.data.size() < 200000;
    }
    match /scores/{uid} {
      allow read: if true;
      allow write: if request.auth != null && request.auth.uid == uid
        && request.resource.data.keys().hasOnly(['name', 'cleared', 'tower', 'contest', 'updated'])
        && request.resource.data.name is string && request.resource.data.name.size() <= 12
        && request.resource.data.cleared is int && request.resource.data.cleared <= 500
        && request.resource.data.tower is int && request.resource.data.tower <= 999
        && request.resource.data.contest is int && request.resource.data.contest <= 300000;
    }
  }
}
```

점수는 브라우저에서 올리는 값이라 마음먹고 조작하면 막을 수 없습니다. 규칙은 말도 안 되는 값만 걸러 냅니다.
